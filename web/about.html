Roblox 0.3.368 browser port

The March 2007 client, rebuilt for HTML, JavaScript and WebGL

This is a playable port of the original Roblox client, version 0.3.368.0, as shipped in March 2007. It runs entirely in the browser: the 3D viewport, the physics, the 2007 interface chrome, the chat and the tool hotbar are all reimplemented in JavaScript on top of WebGL, with no server, no account and no installation.

The engine behaviour was reconstructed from the decompilation of the shipped executable and from the original content files, which are used as the only source of truth for constants, colours, UI layout and script behaviour.

What's included

  • Six classic places: Crossroads, Happy Home in Robloxia, Roblox HQ, Humanoid Harvester Horror, Tabula Rasa and Haunted Mansion.
  • The original character rig, avatar body colours, T-shirt decals and Super Safe Chat phrase book.
  • The 2007 HUD: player list, health bar, backpack hotbar, camera pad and the client's own toolbar labels.
  • Places' embedded Lua scripts, run through a built-in Lua layer.
  • Loading your own .rbxl, .rbxlx or .rbxm XML place files.

Controls

WASD to move, Space to jump, right-drag to turn the camera, mouse wheel to zoom, / to chat, 1–0 for the hotbar. Ladders and trusses climb with W/S.

Technical notes

Everything the client needs (place data, sounds, the character rig, fonts and three.js) is bundled locally. There is no HttpService, so place scripts have no network access, and a Content-Security-Policy blocks remote assets referenced by imported places.
